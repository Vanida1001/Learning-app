# 7. Gamification & progression

Progress is measured in XP and maths-themed ranks, with streaks and badges to keep daily practice going.

**XP rules:**

| Action | XP |
| --- | --- |
| Correct exercise answer | 10 |
| Lesson completed (first time) | 50 |
| Module Contrôle passed (≥ 70 %) | 200 |
| Mini-game played | 5 + score-based bonus (max 50) |
| Error from Carnet d'erreurs corrected | 15 |
| Daily streak bonus | 10 × streak days (max 100) |

**Ranks** (level = floor(√(XP / 50)) + 1, shown as a formula on the profile page):

1. Axiome (level 1–2)
2. Lemme (3–4)
3. Corollaire (5–6)
4. Théorème (7–9)
5. Démonstration (10–12)
6. CQFD (13+)

**Badges** (12 minimum), for example: *Premier commentaire*, *Chasseur de métaphores* (50 figures found), *Zéro paraphrase* (10 PCEI perfect in a row), *Alexandrin parfait*, *Série de 7 jours*, *Boss vaincu*.

**Other features:**

- **Streak**: days in a row with at least one lesson or game; shown with a flame in the header.
- **Objectif du jour**: a daily goal (default 50 XP, adjustable) with a progress ring.
- **Map of the course**: the home screen shows modules as nodes on a path (like a proof tree), locked/unlocked/mastered.
