# 1. Vision & objectives

Build **« Le Théorème du Texte »**: a single-page web app that teaches a French *seconde* student how to analyse literary texts and write a *commentaire* — taught like a maths course, with definitions, formulas, theorems, worked examples and graded exercises.

**Target user:** a lycée student in *seconde* (French curriculum, programme 2019), preparing for the *Bac de français* in *première*. Interface language: French.

**Core learning outcomes.** By the end, the student can:

1. Identify and name the main *procédés* (figures de style, champs lexicaux, temps verbaux, ponctuation, rythme, focalisation, versification) in any text.
2. Turn an observation into an interpretation using a fixed formula (*procédé → citation → effet → interprétation*).
3. Build a *problématique* and a 2- or 3-part *plan* for a *commentaire*.
4. Write a complete *introduction* (5 steps) and *conclusion* (2–3 steps).
5. Write a full *paragraphe argumenté* and, eventually, a short *commentaire*.

**Teaching philosophy — "le français comme les maths":**

- Every method is a **formula** or an **algorithm** with numbered steps, not a vague tip.
- Every notion has a **Définition**, a **Propriété/Théorème**, a **Exemple résolu** and **Exercices** — exactly like a maths textbook.
- Mistakes are treated like calculation errors: the app shows *which step* of the formula failed.
- Progress is built like a proof: a module unlocks only when the previous one is mastered (≥ 70 % on its exercises).

**Fun, but serious:** mini-games reuse the same notions as the lessons, so playing *is* revising. No game exists purely for decoration.
