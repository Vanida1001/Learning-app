# 3. Curriculum — 10 modules, 33 lessons

The course is organised like a maths year: "chapitres" that build on each other. Each module has 3–5 lessons, a set of exercises and a final **Contrôle** (10-question test). A module unlocks when the previous Contrôle is ≥ 70 %.

| # | Module (chapitre) | Lessons | Unlocks game |
| --- | --- | --- | --- |
| 0 | **Axiomes — Lire un texte** | Les 5 questions de départ (Qui ? Quoi ? Quand ? Où ? Comment ?) · Genre, registre, situation d'énonciation · Thème vs. problématique du texte | — |
| 1 | **Les outils de la langue** | Champs lexicaux et connotations · Temps et modes verbaux · Types et formes de phrases, ponctuation · Énonciation (pronoms, modalisation) | Champ lexical Sudoku |
| 2 | **Les figures de style** | Figures d'analogie (comparaison, métaphore, personnification, allégorie) · Figures d'opposition (antithèse, oxymore, chiasme) · Figures d'amplification et d'atténuation (hyperbole, gradation, accumulation, anaphore, litote, euphémisme) · Figures de sonorité (allitération, assonance) | La Chasse aux figures |
| 3 | **Les genres** | Le récit : narrateur, focalisation (interne, externe, omnisciente), rythme (scène, sommaire, ellipse, pause) · La poésie : versification (vers, rimes, strophes, diérèse, enjambement, rejet) · Le théâtre : double énonciation, didascalies, types de répliques · L'argumentation : thèse, arguments, exemples, connecteurs | Le Compteur de syllabes |

**Required content per lesson** (all written in French, in the app):

- At least 1 *Définition*, 1 *Théorème/Propriété* or *Méthode*, 1 *Exemple résolu* using a real public-domain excerpt, and 1 *Attention* box listing the classic mistake.
- At least 6 exercises per lesson (mixed types, see `05-lessons-and-exercises.md`), and 10 questions in each module's Contrôle.
- A **fiche-mémo** (one-screen summary) per module, printable via `window.print()` with print-friendly CSS.

**Suggested excerpts** (public domain, for Claude Code to use): Baudelaire, *L'Albatros*; Hugo, *Demain, dès l'aube…*; Rimbaud, *Le Dormeur du val*; Verlaine, *Chanson d'automne*; La Fontaine, *Le Loup et l'Agneau*; Maupassant, opening of *Bel-Ami*; Zola, *Germinal* (opening); Molière, *L'Avare* IV, 7 (monologue d'Harpagon); Racine, *Phèdre* I, 3 (aveu); Voltaire, *Candide*, chap. 3.

**Œuvres de ma classe** (from the student's reading list; more will be added later):

- **Maupassant, *Bel-Ami* (1885)** — public domain. Use it as the recurring text across modules: at least 4 excerpts (opening, Duroy's first article, a scene with Madeleine, the ending), with lessons and exercises marked with a badge "Œuvre au programme".
- **Yasmina Reza, *Art* (1994)** — still under copyright, so **no quotations in the app**. The app can include the student's own short summary-level context (characters Serge, Marc, Yvan; the white painting; a comedy built on a quarrel between friends) and theatre-specific exercises written without quoting the play.

**Mes textes** (feature): a page where the student pastes a short excerpt from their own copy of a class text (title, author, text). It is saved only in `localStorage`, never shipped in the code. The student can then use it in the generic exercises: highlight procédés, build PCEI analyses, write a problématique and plan. This is how *Art* and future class texts get practised.
